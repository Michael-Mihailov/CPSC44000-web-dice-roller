# Web Dice Roller

## Author

**Michael Mihailov**

## Project Description

This project is a web-based dice roller created for CPSC44000. The application simulates rolling five six-sided dice for the game of Yahtzee.

The website automatically rolls the dice when the page loads and allows the user to roll all five dice again using the **Roll Dice!** button or by pressing **Enter**.

The project demonstrates the use of HTML, CSS, JavaScript, Bootstrap, and random number generation to create a simple and responsive web application.

## Running the Application

### Prerequisites

The application requires:

- A modern web browser
- Visual Studio Code or another text editor
- A local web server

### Running with Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Open `src/index.html`.
4. Right-click `index.html` and select **Open with Live Server**.
5. The dice roller will open in a web browser.

## How to Use

The application displays five six-sided dice.

- The dice are automatically rolled when the page first loads.
- Click **Roll Dice!** to roll all five dice again.
- The **Enter** key can also be used to roll the dice when the button is focused.
- Each die generates a random number from 1 through 6.

## Deployment

The website is hosted using Microsoft Azure and is publicly accessible through an HTTPS URL.
